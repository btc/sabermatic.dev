# Naming & Branding Design Spec

## Brand Identity

- **Brand name:** Sabermetric
- **Domain:** sabermetric.dev
- **Legal entity:** Spanda, LLC → DBA Massive Autonomy → product brand Sabermetric
- **Energetic register:** Analytical rigor on the surface, monk/devotion/craft underneath. The precision is the respect for the craft.

## Landing Page Hero — Rotating Tagline

### Mechanic

Typewriter or fade animation cycling through lines in order, holding the final line indefinitely.

### Sequence

1. *"system design, measured."*
2. *"measure what matters."*
3. *"practice with precision."*
4. *"the science of system design prep."*
5. **"data-driven system design prep."** ← holds

### Timing

~3 seconds per line (enough to read, not enough to get bored). Total animation: ~15 seconds before landing.

### Typography

The tagline sits beneath "sabermetric" in the hero. Lowercase, period-terminated for the confident/quiet tone. The final hold line can optionally drop the period since it's the "functional" descriptor.

### Reserved for Other Contexts

- *"moneyball interview prep"* — social media, tweets, casual marketing copy
- Individual taglines can be pulled for App Store subtitle, meta description, ad copy as needed

## Naming Across the Product

| Context | Format |
|---|---|
| In-app header | "Sabermetric" (no tagline, no `.dev`) |
| Browser tab title | "Sabermetric — data-driven system design prep" |
| Meta description / OpenGraph | Defaults to descriptive final line for SEO and link previews |
| Verbal / conversational | "Sabermetric" — one word, no qualifier |
| Logo / wordmark | Lowercase "sabermetric" (quiet confidence tone) |
| Prose | Capitalized "Sabermetric" |
