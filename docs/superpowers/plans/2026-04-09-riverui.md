# River UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mount River UI at `/admin/jobs/` in the existing server, protected by the existing admin auth middleware, accessible in production.

**Architecture:** `Backend` owns the riverui lifecycle (construction, start, stop) alongside the existing `river.Client`. A `RiverUIHandler()` accessor on `Backend` returns the pre-built `http.Handler`, which `RegisterRoutes` mounts under `/admin/jobs/` wrapped in the existing `requireAuth(requireAdmin(...))` chain.

**Tech Stack:** `riverqueue.com/riverui` v0.15.0, `riverqueue/river` v0.32.0 (already installed), Go 1.22 `net/http` ServeMux, gorilla/csrf.

**Spec:** `docs/superpowers/specs/2026-04-09-riverui-design.md`

```go
func (b *Backend) Close() error {
	b.closeRiverUI()

	timeout := time.Duration(b.cfg.River.ShutdownTimeoutSec) * time.Second
	ctx, cancel := context.WithTimeout(context.Background(), timeout)
	defer cancel()
	if err := b.jobs.Stop(ctx); err != nil {
		slog.Warn("river stop error", "error", err)
	}
	slog.Info("river stopped")

	if err := b.store.Close(); err != nil {
		slog.Warn("storage close error", "error", err)
	}

	b.pool.Close()
	slog.Info("database pool closed")
	return nil
}
```

## Task 2: Mount riverui in routes + delete admin.go

These file changes must be staged and committed together — deleting `admin.go` removes `AdminJobsPlaceholder`, which `routes.go` currently references.

**Files:**
- Delete: `internal/handler/admin.go`
- Modify: `internal/handler/routes.go`

- [ ] **Step 1: Delete admin.go**

Delete the file `internal/handler/admin.go` entirely.

- [ ] **Step 2: Replace the placeholder mount in routes.go**

In `internal/handler/routes.go`, in `RegisterRoutes`, replace:

```go
mux.Handle("GET /admin/jobs", requireAuth(requireAdmin(AdminJobsPlaceholder())))
```

with:

```go
mux.Handle("/admin/jobs/", requireAuth(requireAdmin(b.RiverUIHandler())))
```

The pattern changes from `GET /admin/jobs` (exact match, GET only) to `/admin/jobs/` (prefix match, all methods). This is required so riverui's internal API routes at `/admin/jobs/api/...` are covered by the same auth chain.

- [ ] **Step 3: Add the CSRF exemption in csrfMiddleware**

In `internal/handler/routes.go`, in the `csrfMiddleware` function, add a standalone prefix check for riverui **before** the existing ConnectRPC loop. The result should look like:

```go
return SecurityHeaders(secureCookies, http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
    // Stripe webhook — exempt from CSRF; uses Stripe signature verification.
    if r.URL.Path == "/api/webhooks/stripe" && r.Method == http.MethodPost {
        next.ServeHTTP(w, r)
        return
    }
    // River UI — exempt from CSRF; uses application/json bodies which cannot be
    // submitted cross-origin by a simple HTML form. Auth is enforced by the mux chain.
    // TODO: flip csrfMiddleware to opt-in model — exempt list is growing.
    if strings.HasPrefix(r.URL.Path, "/admin/jobs/") {
        next.ServeHTTP(w, r)
        return
    }
    // ConnectRPC — exempt from CSRF; POST with custom Content-Type headers
    // cannot be sent by simple HTML forms without CORS preflight.
    for _, prefix := range connectPrefixes {
        if strings.HasPrefix(r.URL.Path, "/"+prefix+"/") {
            next.ServeHTTP(w, r)
            return
        }
    }
    ...
```

Do NOT add `/admin/jobs/` to `rpc.ConnectPathPrefixes()` — that slice lacks leading slashes and the loop would build `"//admin/jobs//"`, which never matches.
